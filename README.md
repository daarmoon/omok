# OMOK — 실시간 1:1 오목

반투명하게 빛나는 유리 질감 돌로 두는 실시간 온라인 오목입니다.
서버 하나(Node.js)에서 웹페이지와 실시간 통신(WebSocket)을 같이 처리합니다.

## 기능

- **방 만들기 / 링크로 초대**: 4자리 방 코드 + 초대 링크(모바일에서는 공유 시트)
- **실시간 대국**: 서버가 차례, 착수 위치, 5목 승리를 모두 검증합니다(클라이언트 조작 불가)
- **규칙 선택**: 자유룰(5목 이상이면 승리) / 쌍삼 금지(흑·백 모두, 금수 자리는 판에 ✕로 표시)
- **수당 제한시간**: 없음 / 15초 / 30초 / 60초. 시간이 지나면 패배합니다
- **무르기 요청·수락, 기권, 재대국**(재대국 때 흑·백 교대, 점수 누적)
- **재접속**: 새로고침하거나 잠깐 끊겨도 자리가 유지됩니다
- **관전**: 두 자리가 다 찬 방에 들어오면 관전자로 입장합니다
- **채팅**, 유리 돌 효과음(소리 끄기 가능)
- **모바일 대응**: 터치는 같은 자리를 두 번 탭해야 착수돼서 오터치를 막아 줍니다. 폴드처럼 세로로 긴 화면에서는 세로 배치로 바뀝니다

## 1. 내 컴퓨터에서 실행

[Node.js](https://nodejs.org) 18 이상이 필요합니다(LTS 버전 설치를 권장합니다).

```bash
cd omok-battle
npm install      # 처음 한 번만
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다.
혼자 테스트할 때는 **같은 브라우저에서 탭을 두 개** 열어 한쪽에서 방을 만들고, 다른 탭에서 초대 링크로 들어가면 됩니다.

## 2. 같은 와이파이의 친구와

`npm start` 를 실행하면 터미널에 이런 주소가 나옵니다.

```
같은 와이파이에서: http://192.168.0.12:3000
```

친구 폰이나 노트북에서 그 주소로 접속하면 됩니다.
맥에서 "들어오는 연결을 허용할까요?" 창이 뜨면 **허용**을 누르세요.

## 3. 인터넷으로 어디서든 (서버 공개)

### A. 지금 바로 공개하기: Cloudflare 임시 터널 (무료, 가입 없음)

맥이 켜져 있는 동안만 열려 있는, 가장 간단한 방법입니다.

```bash
brew install cloudflared                       # Homebrew가 없다면 cloudflare 공식 사이트에서 설치
npm start                                      # 터미널 1
cloudflared tunnel --url http://localhost:3000 # 터미널 2
```

`https://xxxx-xxxx.trycloudflare.com` 같은 주소가 나오면 그 주소로 들어가서 방을 만들고, 초대 링크를 친구에게 보내면 됩니다.
주소는 실행할 때마다 바뀝니다.

### B. 항상 접속 가능한 링크: GitHub + Render (무료)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

GitHub에 올린 뒤 이 README의 버튼을 누르면 `render.yaml` 설정대로 서버가 자동으로 만들어집니다.

**① GitHub에 올리기 (git 설치 필요 없음)**
1. github.com 에서 **New repository** → 이름(예: `omok-battle`) → **Public** → Create
2. 만들어진 빈 저장소 화면에서 **uploading an existing file** 클릭
3. 압축을 푼 `omok-battle` 폴더 **안의 내용물**(`public` 폴더, `server.js`, `package.json`, `render.yaml` …)을 전부 끌어다 놓고 **Commit changes**
   - 폴더 자체를 끌어다 놓으면 한 단계 안쪽에 들어가서 Render가 설정 파일을 못 찾습니다.

**② Render에 배포하기**
1. 저장소 첫 화면(README)의 **Deploy to Render** 버튼 클릭 → GitHub 계정으로 Render 로그인
2. 서비스 목록(`omok-battle`, Free)을 확인하고 **Apply / Deploy**
3. 1~3분 뒤 상태가 **Live**가 되면 `https://omok-battle-xxxx.onrender.com` 주소가 생깁니다. 이 주소가 접속 링크입니다.

버튼이 안 보이면 Render 대시보드에서 **New → Blueprint** 를 누르고 저장소를 선택해도 똑같이 됩니다.
코드를 고쳐서 GitHub에 다시 올리면 자동으로 다시 배포됩니다.

**무료 플랜 특징**
- 15분 동안 아무도 접속하지 않으면 서버가 잠들고, 다음 첫 접속 때 30초~1분 정도 깨어나는 시간이 걸립니다. 대국 중에는 화면이 4분마다 신호를 보내서 잠들지 않습니다.
- 서버가 잠들거나 다시 배포되면 진행 중이던 방은 사라집니다.
- 항상 켜 두고 싶으면 Render 유료 인스턴스로 바꾸면 됩니다.

Railway나 Fly.io처럼 Node 서버와 WebSocket을 지원하는 곳이라면 같은 방식으로 올릴 수 있습니다.
포트는 환경변수 `PORT` 를 자동으로 따릅니다.

> 방과 대국 기록은 서버 메모리에만 있어서, 서버를 재시작하면 사라집니다.
> 아무도 없는 방은 30분 뒤 자동으로 정리됩니다.

## 파일 구조

```
omok-battle/
├─ server.js          # HTTP + WebSocket 서버, 방·차례·승패·타이머 관리
├─ package.json
└─ public/
   ├─ index.html      # 로비 / 게임 화면
   ├─ style.css       # 디자인 (배경 오로라, 유리 패널, 판)
   ├─ app.js          # 실시간 통신, 캔버스 렌더링(유리 돌), 입력, 사운드
   └─ rules.js        # 5목·쌍삼 판정 (서버와 브라우저가 같은 코드 사용)
```

## 꾸미기

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 돌 색·투명도·광택 | `public/app.js` 의 `makeStone()` 안에 있는 색상값 (`rgba(...)`) |
| 돌 주변 빛 번짐 세기 | `app.js` 의 `frame()` 1번 단계 `a = (… 0.72 : 0.6) + 0.16 * …` |
| 돌 너머로 격자가 비치는 정도 | `frame()` 2-b 단계 `globalAlpha = (… 0.62 : 0.5)` |
| 판 색·배경 | `public/style.css` 의 `.board-frame`, `body` |
| 격자선 색 | `app.js` 의 `makeGrid()` |
| 제한시간 선택지 | `server.js` 의 `TIMER_OPTIONS` + `index.html` 버튼 |

## 규칙 메모

- 흑이 먼저 둡니다. 가로·세로·대각선으로 5개를 먼저 이으면 이깁니다(6목 이상도 승리로 인정).
- **쌍삼 금지**는 한 수로 열린 3을 두 개 이상 동시에 만드는 수를 막습니다. 단, 그 수로 5목이 완성되면 둘 수 있습니다. 4-3은 허용됩니다.
- 무르기는 상대가 수락하면 요청한 사람의 마지막 수까지 되돌립니다.
